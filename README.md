# FTR-Simulasyon

Fizik tedavi rehabilitasyon (FTR) tedavi **simülasyonu** — React ve Vite ile geliştirilmiş öğrenci projesi arayüzü.

**Önemli:** Bu proje tıbbi tanı, tedavi veya egzersiz reçetesi sunmaz; yalnızca **bilgilendirme ve demo** amaçlıdır. Sağlık sorununuz için mutlaka bir hekim veya lisanslı fizyoterapistle görüşünüz.

## Çalıştırma

Kaynak kod ve kurulum adımları `FTR/ftr-tedavi-simulasyonu` klasöründedir:

```bash
cd FTR/ftr-tedavi-simulasyonu
npm install
npm run dev
```

İsterseniz kök dizinden gösterim ekranı görüntüsünü `docs/screenshot.png` gibi bir yola ekleyerek rapor veya bu README içinde referans verebilirsiniz.
